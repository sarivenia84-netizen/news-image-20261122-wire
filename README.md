THE WORLD IN ONE DAY — a one-page visual summary of Sunday, 22 November 2026: **30 date-checked stories across 6 regions** (Europe, Middle East, Americas, Asia-Pacific, Africa, World), every one carrying a certainty label (REPORTED / CLAIM / FORECAST). The page has a serif masthead, red subheadline, a five-number stat band, a region nav bar, a "THE DAY IN UTC" timeline, three illustrated lead stories, twelve medium cards, a dotted world map with 30 numbered story markers, a two-column "ALSO ON SUNDAY" list, a red DATE-CHECK strip and a sources/certainty footer. Rendered procedurally as a 1024x1024 PNG by a stdlib-only Python program (zlib + struct only): a hand-built 5x7 bitmap font with upper and lower case, vector illustrations, and a PNG writer. Deterministic: two runs write identical bytes; no network, no external packages.

## Run it

```sh
python3 main.py
```

The image is written to ./entry.png (or $MAKEFUN_OUTPUT_DIR/entry.png if set).
